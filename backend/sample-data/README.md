# SAMPLE DATA - fictional

All companies, people, accounts and amounts in this folder are **invented for demonstration**.
Any resemblance to real entities is coincidental. Account numbers are masked placeholders.

- `nile-foods.invoices.json` - open receivables of the sample tenant "Nile Foods Distribution (SAMPLE)"
- `nile-foods.bank-feed-oct-2026.csv` - combined statement lines from 3 bank accounts (EGP + USD)
- `lotus-textiles.*` - second sample tenant (partial payments), used to show tenant isolation
